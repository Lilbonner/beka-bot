# 👻 БЕКС — бот-призрак ливнувших

Telegram-бот, который тихо собирает сообщения участников группы, а когда кто-то
**ливает из чата** — иногда оживает и говорит его фразами. Фразы строятся
гибридно: часть — настоящие цитаты человека, часть — «франкенштейн»-фразы,
склеенные из его слов цепями Маркова.

## Как это работает

1. Бот пишет каждое текстовое сообщение в SQLite (`chat_id`, `user_id`, текст).
2. Когда участник выходит/кикнут — он помечается как «призрак».
3. Призраком становится тот, кто **ушёл** и оставил **≥ `MIN_MESSAGES`** сообщений.
4. Бот «оживает» тремя способами:
   - **случайно** — с вероятностью `TRIGGER_PROBABILITY` отвечает на сообщение;
   - **по команде** `/ghost`;
   - **в тишине** — если в чате нет активности дольше `IDLE_MINUTES`, пишет сам.

## Стек

- **Node.js 22.5+** (встроенный `node:sqlite` — без нативной сборки)
- **grammY** — единственная зависимость

## Установка

```bash
npm install
copy .env.example .env   # на macOS/Linux: cp .env.example .env
```

Впиши в `.env` токен бота от [@BotFather](https://t.me/BotFather).

## Настройка бота в BotFather (важно!)

1. `/newbot` → получи токен.
2. **Отключи приватный режим** (иначе бот видит только команды, а не сообщения):
   `/setprivacy` → выбери бота → **Disable**, затем **переподключи бота в группу**.
3. Для надёжного отлова выхода участников (`chat_member`) — **выдай боту права
   администратора** в группе.

## Запуск

```bash
npm start      # обычный запуск
npm run dev    # с авто-перезапуском при правках (--watch)
```

## Команды

| Команда            | Действие                                              |
| ------------------ | ----------------------------------------------------- |
| `/ghost`           | Вызвать случайного призрака                            |
| `/ghosts`          | Список призраков чата                                  |
| `/chatid`          | ID чата (нужен для импорта истории)                    |
| `/users`           | Участники с ID и числом сообщений (админам)            |
| `/makeghost <id>`  | Пометить юзера призраком (админам)                     |
| `/unghost <id>`    | Снять метку призрака (админам)                         |
| `/help`            | Помощь                                                 |

## Импорт истории

Bot API не отдаёт историю чата, поэтому прошлые сообщения берутся из экспорта
Telegram Desktop (⋮ → «Экспорт истории чата»). Поддерживаются оба формата —
**JSON** (`result.json`) и **HTML** (папка с `messages*.html`).

```bash
# посмотреть, кто есть в экспорте
node --disable-warning=ExperimentalWarning src/import.js <путь> --list

# импортировать только одного человека и сделать его призраком
node --disable-warning=ExperimentalWarning src/import.js <путь> --only <id|имя>
```

`--chat` берётся из `CHAT_ID` в `.env`, если не передан явно.

## Конфигурация (`.env`)

| Переменная             | По умолчанию      | Описание                                       |
| ---------------------- | ----------------- | ---------------------------------------------- |
| `BOT_TOKEN`            | —                 | Токен от BotFather (обязательно)               |
| `CHAT_ID`              | —                 | ID целевого чата (дефолт для импорта)          |
| `DB_PATH`              | `./data/beks.db`  | Путь к файлу базы                              |
| `TRIGGER_PROBABILITY`  | `0.18`            | Шанс, что бот сам встрянет в сообщение (0..1)   |
| `IDLE_MINUTES`         | `60`              | Тишина дольше N минут → бот пишет сам (0 = off) |
| `MIN_MESSAGES`         | `20`              | Минимум сообщений, чтобы ушедший стал призраком |
| `VERBATIM_PROBABILITY` | `0.4`             | Шанс дословной цитаты вместо генерации (0..1)    |
| `MARKOV_ORDER`         | `2`               | Порядок цепи: 1 — хаотичнее, 2 — связнее        |
| `MARKOV_MAX_WORDS`     | `40`              | Максимум слов во фразе                          |
| `SHOW_GHOST_NAME`      | `true`            | Показывать имя призрака перед фразой            |

## Структура

```
src/
├── config.js     # чтение .env и настроек
├── db.js         # SQLite: сбор сообщений, отметки выхода, выборки
├── markov.js     # генератор цепей Маркова
├── ghost.js      # выбор призрака и генерация его реплики
├── index.js      # бот grammY: команды, обработчики, idle, ретраи
├── parseHtml.js  # парсер HTML-экспорта Telegram Desktop
└── import.js     # импорт истории (JSON/HTML)
```

## Этика

Бот хранит и воспроизводит сообщения участников. Используй его только в дружеских
чатах, где это уместно, и предупреди участников, что такой бот работает.
